▸ Agentic RL 算法研发
  • 发现长程 Agentic RL 训练后期性能停滞/崩溃的一个关键原因是轨迹中的大量无效交互，通过提前截断轨迹 + token 掩码提升训练稳定性与上限【NeurIPS 2026, ICLR2027 在投】
  • 提出解耦熵约束策略，实现大模型使用工具时依据问题复杂度自适应调整快慢思考模式 【AutoTool, ICLR 2026】
  • 完成华为昇腾生态训练适配，初步探索 RL 训练反馈信用分配机制【iTool EMNLP 2025；Tool Zero EMNLP 2025】
▸ Harness Agent 训练体系搭建
  • 构建 SFT 数据生产流水线，产出 2+ 万条数据、覆盖 42 类 Harness 使用场景，支撑大规模 Agent 训练数据供给【NeurIPS 2026】
  • 主导搭建 139 个 Agentic RL Tool 环境，支撑业务 Agentic RL 先导探索【ICLR 2027 在投】
  • 设计轻量化 Harness，支撑大规模在线 In-Harness RL 训练，训练资源开销减少 8 倍、推理开销减少 32%【AAAI 2027 在投】
▸ Agent 指令遵循性能提升
  • 发现 RL 影响指令遵从能力的关键瓶颈是反馈信号质量，提出多约束下的密度控制，低成本提升指令遵从性能上限，落地小艺自研模型，对话满意度 81→89【ICLR 2027 在投】
  • 轻量专家集成方法缓解多约束场景下强化学习的 reward hack 问题：平均性能 +10%、奖励精度 +12%、训练速度 3× 【TinyJudge, ACL 2026】
  • 探索在线策略蒸馏（OPD）在指令遵从中的应用，解耦-聚合修正教师在多约束下的分布，性能 +4%【ICLR 2027 在投】

指令遵循（Instruction Following）

  • 在给出回答的同时额外满足用户指定的约束条件，是智能体对话与长程任务执行的必备能力
  • 研究覆盖：RL 训练下指令遵从泛化性机制与上限提升（ACL 2026、ICLR 2027 在投）、多模态指令遵循 RL 数据合成（ACL-ARR 在投）、在线策略蒸馏 OPD 在其上的应用（ICLR 2027 在投）
